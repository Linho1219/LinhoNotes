## 点状特征表达

- 中心点 → 空间定位信息
- 形状、颜色 → 质量特征
- 大小 → 数量指标

### 定点符号法

表示质量信息：形状、颜色、网纹、方向

表示数量信息：

| 表达地图信息的强度或排序     | 表达地图信息的数量差别     |
| ---------------------------- | -------------------------- |
| 顺序量表                     | 间距 / 比率量表            |
| 尺寸变量，辅以亮度、彩度变量 | 尺寸变量为主，精确表达差异 |
| 非比率定位符号               | 比率定位符号               |

从要素数值 $M$ 确定符号大小 $L$ 的方法：

- 连续方式
  - 绝对比率符号（平方根法）：$L=k\sqrt M$
    - 优点：符号面积之比与数值之比吻合
    - 缺点：数值差异不能过大或过小
  - 相对比率符号（条件比率符号）
    - 常数比率 $L=kM$
    - 线性比率 $L=aM+b$
    - 对数比率 $L=k\ln M$
    - 心理比率 $L=kM^{0.57}$

  确定 $k$ 的原则：最小值符号清晰可辨，最大值符号尺寸适宜

- 分级方式：按一定数值间隔分级，各级符号大小的确定可以再使用绝对或条件法

  - 优点
    - 容易确定符号大小
    - 简化图例，便于读者读图
    - 在一定时期内保持地图的现势性

  - 缺点：无法表示同一级专题要素在数量指标上的差别

### 点状符号的定位

- 概略定位：符号位置合理
- 精确定位：符号重心或底点与地物位置重合

```markmap

- 线状符号法
  - 主要方向
  - 数量特征
  - 质量特征
  - 时间变化
- 动线法 (箭头)
  - 路线
  - 方向
  - 速度
```

线状符号的定位：

- 精确定位

  - 适用：具有明确且稳定空间路径的线状现象

  - 举例：经纬线、境界线、铁路、油气管线、线性构造

  - 注意：符号宽度表示属性特征差异，不代表实际的宽度

- 概略定位

  - 适用：在一定范围内呈动态变化的线状现象或不易明确路径的移动现象
  - 举例：洋流、台径、人口迁徙
  - 注意：线状符号的图上坐标不具有量测或实际的定位意义

### 面状现象的空间分布形态

四种空间分布形态：

- 连续渐变：地貌、气温、气压
- 连续突变：地质构造、行政区划、综合自然区划
- 离散渐变：人口、动植物、矿产资源、城镇
- 离散突变：湖泊、水库、洪水淹没区、冰川分布区、作物种植区

连续分布与离散分布：

- 连续分布：连续无间断地布满整个制图区域
- 离散分布：相互聚集但又彼此间隔、相互独立

精确定域与概略定域：

- 精确定域：有详尽的制图数据，有准确的分布范围——实线
- 概略定域：渐变、动态、范围模糊、不易确定（土壤、民族、植被、自然区划等）——虚线

### 面状特征定性信息的表达

| 分布方式     | 常用方法 | 对应地图类型   |
| ------------ | -------- | -------------- |
| 全域连续分布 | 质底法   | 类型图、区划图 |
| 区域成片分布 | 范围法   | 分布范围图     |
| 离散分布     | 范围法   | 分布图         |

- 质底法：以**充满全制图区**的不同颜色或图案的图斑，表示不同**面状连续分布**现象质量特征
- 范围法：通过轮廓线、颜色或网纹、图案表示**面状离散分布**现象真实或隐含的分布范的方法，可能重叠

### 面状特征定量信息的表达

- 以点状符号构成的定量表达
  - 点值法：用形状相同、**大小**与其代表的**数值成固定比率**的点状符号表达离散现象分布特征。
    - 步骤：确定区域单元 → 确定单元内数据的分布位置 → 计算点值和点的尺寸 → 作图
    - 布点方式：均匀布点法、定位布点法
    - 能达到制图区域内数量对比的效果，但不适宜准确的定位
  - 分区统计图表法：将制图对象在**统计分区的绝对数量指标**以点状符号（统计图表）表达
  - 定位图表法：将制图对象在**数据采集点的绝对数量指标**以点状符号（统计图表）表达
