## 基本概念

### 基本图元信息

在计算机中表示一个图形 首先要确定构成图形的基本元素。**基本图形元素（图元）是构成复杂图形的最小不可分割单元**，主要包括四类：点、线、面、体。

- 点（point）：最基本的图形元素，只有位置没有大小
  - 二维为 $(x,y)$，三维为 $(x,y,z)$
  - 是构成线、面、体的基础，任何几何形体都可以看作是点的集合
- 线（line）：线由两个端点确定
  - 直线段是最简单的线元素，曲线可以由一系列离散点近似表示或用参数方程描述
  - AutoCAD 中，Line 对象表示直线段，Polyline 对象可以表示由多段直线或弧线组成的复合线
- 面（face/surface）：由有序顶点序列围成
  - 最简单的面是三角形面，由三个顶点确定；多边形面由多个顶点按一定顺序连接围成
  - 面的法线方向由顶点的排列顺序（通常为逆时针）按右手定则确定
  - 在三维图形中，面是构成封闭体的基本单元
- 体（Solid）：由面围成的封闭空间区域
  - 表示方法有边界表示（B-reps）、构造实体几何（CSG）、空间分割等

在 AutoCAD VBA 中，可以通过 ModelSpace 对象的各种 `Add` 方法创建基本图元。下面的代码展示了如何创建点、线、多边形等基本图元：

```vb
' === 创建基本图元示例 ===
Sub CreateBasicPrimitives()
  Dim pt(0 To 2) As Double
  Dim i As Integer

  ' 1. 创建点 (Point)
  pt(0) = 0 : pt(1) = 0 : pt(2) = 0
  Dim pointObj As AcadPoint
  Set pointObj = ThisDrawing.ModelSpace.AddPoint(pt)

  ' 2. 创建直线 (Line)
  Dim pt1(0 To 2) As Double, pt2(0 To 2) As Double
  pt1(0) = 0 : pt1(1) = 0 : pt1(2) = 0
  pt2(0) = 10 : pt2(1) = 5 : pt2(2) = 0
  Dim lineObj As AcadLine
  Set lineObj = ThisDrawing.ModelSpace.AddLine(pt1, pt2)

  ' 3. 创建多边形 (LightWeightPolyline)
  Dim pts(0 To 9) As Double
  ' 三角形： (0，0) -> (5，0) -> (2.5， 4.33) -> 闭合
  pts(0) = 0 : pts(1) = 0
  pts(2) = 5 : pts(3) = 0
  pts(4) = 2.5 : pts(5) = 4.33
  pts(6) = 0 : pts(7) = 0 ' 闭合
  Dim plineObj As AcadLWPolyline
  Set plineObj = ThisDrawing.ModelSpace.AddLightWeightPolyline(pts)
  plineObj.Closed = True

  ' 4. 创建三维面 (3DFace)
  Dim face1(0 To 2) As Double, face2(0 To 2) As Double, _
    face3(0 To 2) As Double, face4(0 To 2) As Double
  ' 四边形面： 4个顶点
  face1(0) = 0 : face1(1) = 0 : face1(2) = 0
  face2(0) = 5 : face2(1) = 0 : face2(2) = 0
  face3(0) = 5 : face3(1) = 5 : face3(2) = 0
  face4(0) = 0 : face4(1) = 5 : face4(2) = 0

  Dim faceObj As Acad3DFace
  Set faceObj = ThisDrawing.ModelSpace.Add3DFace(face1, face2, face3, face4)

  MsgBox "基本图元创建完成：1个点，1条线，1个多边形，1个三维面"
End Sub
```

### 几何信息与拓扑信息

图形的描述信息包括**几何信息**和**拓扑信息**。

- 几何信息（Geometric Information）：描述图形位置、大小和形状的度量信息，确定了图形在空间中的具体位置和形状
- 拓扑信息（Topological Information）：描述图形各组成部分之间连接关系的信息，确定了图形的结构关系

相同的几何信息、不同的拓扑信息会产生不同的图形。如下图，5 个顶点的坐标（几何信息）完全相同，但由于连接顺序不同（拓扑信息不同）， 一个形成凸五边形，另一个形成五角星形。

![](./images/topo-info.svg)

一个好的图形数据结构应当既能高效存储几何信息，也能快速检索拓扑关系。

刚体运动：不改变图形上任意两点间距离，也不改变图形几何性质的运动。平移和旋转属于刚体运动。刚体运动会改变几何信息，但不会改变拓扑信息。

拓扑等价：允许形体作弹性运动（即可以随意伸张扭曲），但不允许把不同的点合并为一个点。在拓扑关系中，一个圆和一个正方形是拓扑等价的，因为它们都可以通过弹性变形相互转化。

### 邻域、开闭集

点的邻域 $B_r(P)$：如果 $P$ 是点集 $S$ 的一个元素， 那么点 $P$ 的以 $r$（$r>0$）为半径的邻域 $B_r(P)$ 指的是围绕点 $P$ 的半径为 $R$ 的小球（二维情况下为小圆）。邻域是判断点属于内点还是边界点的基础。

点的去心邻域 $\mathring B_r(P)$：排除 $P$ 自身后的邻域，即 $\mathring B_r(P)=B_r(P)\backslash\{P\}$。

基于邻域的概念，定义与点集有关的点：

- 内点：对于点 $P$，存在完整包含于 $S$ 的邻域，即 $\exists r$ 使 $B_r(P)\sub S$。显然内点 $P\in S$。
- 外点：对于点 $P$，存在与 $S$ 不相交的邻域，即 $\exists r$ 使 $B_r(P)\cap S=\varnothing$。显然外点 $P\notin S$。
- 边界点：对于点 $P$，其邻域必须同时与 $S$ 与 $S$ 的补集相交，即 $\forall r$ 有 $B_r(P)\cap S\ne\varnothing$ 且 $B_r(P)\cap S^\complement\ne\varnothing$。显然内点、外点、边界点是三选一的关系。
- 孤立点：对于点 $P$，其任意邻域与集合 $S$ 的交集只有它自己，即 $\forall r$ 有 $B_r(P)\cap S=\{P\}$。显然孤立点 $P\in S$。孤立点必是边界点。
- 极限点：对于点 $P$，其去心邻域必须与 $S$ 相交，即 $\forall r$ 有 $\mathring B_r(P)\cap S\ne\varnothing$。内点必是极限点，孤立点必不是极限点，非孤立点的边界点必是极限点。

定义开集与闭集：

- 开集：所有点都是内点的点集。通俗地说就是不包含边界的点集。
  - 若干个开集的交集、并集仍是开集
  - 全集和空集也属于开集
  - 孤立点不构成开集，开集中所有的点都是极限点
- 闭集：一个补集为开集的点集。通俗地说就是包含边界的点集。
  - 闭集所有的极限点都在闭集中
  - 闭集的交集、并集仍是闭集

### 实体的定义

定义**正则集**（regular set）：由内部点构成的点集的闭包，三维空间中的正则集就是正则形体，即有效实体。

定义正则化操作：$S^*=\operatorname{closure}(\operatorname{interior}(S))$

![](./images/regularize.svg)

先只保留所有内点，去除边界、悬边、孤立点，然后再补回边界。

定义**二维流形**：对于实体表面上的**任意**一点，都可以找到一个围绕它的任意小的邻域， 该邻域与平面上的一个圆盘是拓扑等价的。直观地说，实体表面上的每一点都有明确的「内部」和「外部」。包含悬边、孤立点的实体不是二维流形；若有多个封闭体共顶点或共棱，也不是二维流形。

定义**实体**：对于一个占据有限空间的正则形体，如果其表面是二维流形，则该正则形体为实体。

实体具有如下性质：

- 有界性：实体占据有限的空间区域。
- 封闭性：实体的表面将空间分为内部和外部两部分。
- 确定性：给定一个位置， 可以明确判断该位置是在实体内部、外部还是表面上。
- 维数一致性：实体的表面是二维流形， 不存在一维的悬垂边或零维的孤立点。

### 正则集合运算

构造复杂实体时常需把简单实体通过并、交、差组合起来，但是普通集合运算可能产生非正则结果：

- 两立方体共面放置，普通并集留下内部悬垂面
- 两仅边缘接触的立方体求交，得到一条悬垂边

因此定义三种正则集合运算：

- 正则交 $A\cap^*B=\operatorname{closure}(\operatorname{interior}(A\cap B))$
- 正则并 $A\cup^*B=\operatorname{closure}(\operatorname{interior}(A\cup B))$
- 正则差 $A-^*B=\operatorname{closure}(\operatorname{interior}(A-B))$

其中 $\cap,\cup,-$ 为普通交、并、差运算。其本质是先做普通运算，再对结果做正则化处理

正则集合运算的性质：

- 封闭性：结果仍是正则集（有效实体）
- 满足结合律
- 正则并、正则交满足交换律
- 在 AutoCAD 中，三维实体的 Boolean 运算自动执行正则集合运算

### 平面多面体与欧拉公式

平面多面体是由平面多边形围成的封闭三维形体，是实体表示中最基本的形体之一。每个面都是平面多边形，相邻面共享一条边，每条边连接两个顶点。

**简单多面体的欧拉公式**：

$$
V-E+F=2
$$

其中 $V$ 为顶点数，$E$ 为边数，$F$ 为面数。

该式对所有简单多面体（无贯穿孔）都成立。例如立方体由 $V=8$，$E=12$，$F=6$，则由 $8-12+6=2$。

对带孔或通孔的多面体，简单欧拉公式不再成立，适用**扩展欧拉公式**：

$$
V-E+F-H=2(C-G)
$$

其中新增的字母含义：$H$ 为表面上的孔数，$G$ 为贯穿孔数，$C$ 为独立、不相连接的多面体数。

欧拉公式的意义在于：它**可以作为验证多面体表示有效性的工具**。如果一个多面体的顶点、边、面数据不满足欧拉公式，则说明该表示存在错误（如缺少面、多余的边等）。在 CAD 系统的数据一致性检查中，欧拉公式是一种重要的验证手段。
