# 计算机图形学

<Tag orange>更新中</Tag>

同济大学测绘专业选修课程，课号 `CSG350901` / `03035301`。

课程依托 AutoCAD 中的 VBA 编程。使用自编教材，本笔记大部分内容截取自该教材。

对于在校学生，可以前往 AutoDesk 官网 [申请学生许可证](https://www.autodesk.com.cn/education/edu-software/overview?sorting=featured&filters=individual)，填写本人姓名并上传证明文件（例如在读证明、成绩单）等，即可获得免费的教育版许可。安装 AutoCAD 后，需要额外下载 [Microsoft VBA Module for AutoCAD](https://www.autodesk.com/support/technical/article/caas/tsarticles/ts/3kxk0RyvfWTfSfAIrcmsLQ.html) 才能使用 VBA 功能。
