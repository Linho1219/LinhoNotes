# 2 VBA 基础

## VBA 语法基础

VBA 中，**关键字不区分大小写**，变量名默认区分大小写。整体上，VBA 是 Pascal 风格，即首字母大写、词首字母大写，例如 `MsgBox`。不过为了方便，大部分代码中声明变量时还是使用驼峰或下划线命名。

通常格式化工具会将可识别的关键字和命令修改为首字母大写、其他小写的形式，例如 AutoCAD 的 VBA 编辑环境就会在换行时自动修改大小写。

VBA 每行一个语句，结尾不加分号。若要将语句拆分至多行，需要在行尾添加续行符 `_`。

### 注释

使用 `'` 表示单行注释。VBA 没有多行注释。

```vb
' 这是注释
```

### 变量与数据类型

模块顶部应始终添加 `Option Explicit`，表示在使用变量前必须声明。地位类似于 JS 的 `'use strict'`。

使用 `Dim <变量名> As <类型名>` 声明变量，可以同时声明多个：`Dim <变量名1> As <类型名1>, <变量名2> As <类型名2>`。**变量声明时不能按值初始化**，变量初始值为对应类型的初始值。

使用 `Const <常量名> As <类型名> = <值>` 声明常量。常量在声明时必须一并提供值。

基本类型：

- `Integer`：16 位整数（历史原因），少用
- `Long`：32 位整数，通常整数用这个
- `Single`：单精度浮点数
- `Double`：双精度浮点数
- `String`：字符串，长度任意
- `Boolean`：布尔值，比较特别的是占 2 字节
- `Date`：时间戳
- `Variant`：可变类型，类似 C++ 的 `std::any`，性能较差

未显式指定类型的变量默认为 `Variant` 类型。
