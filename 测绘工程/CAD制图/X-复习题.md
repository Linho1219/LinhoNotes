# X 复习题

## AutoCAD 提供了哪 3 种工作空间？

草图与注释、三维基础、三维建模。

## AutoCAD 经典空间界面包括哪些元素？

程序图标、快速访问工具栏、菜单栏、工具栏、绘图区、命令行窗口和状态栏。

## AutoCAD 执行命令的方式有哪 3 种？

- 通过菜单栏执行命令
- 通过工具栏按钮执行命令
- 命令行输入命令执行

## 如何取消、放弃或恢复？

- 如何取消当前正在执行的命令？按 <kbd>Esc</kbd> 取消。
- 如何放弃上一次执行的命令？执行 `U` 或 `UNDO` 命令。
- 如何放弃前面n次执行的命令？先执行 `UNDO` 命令再输入 n。
- 如何恢复已撤销的命令？执行 `REDO` 命令。
- 如何再次执行不久前执行过的命令？按上下方向键选择执行过的命令后回车。
