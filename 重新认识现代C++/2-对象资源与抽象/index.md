# 2 对象、资源与抽象

这一篇讨论函数接口、类与不变式、RAII、所有权、复制与移动，以及运行时多态、模板和标准库组件。重点不是记住全部语法，而是学会用类型表达约束、管理资源，并利用已有组件组合出可读的程序。

- **[2.1 如何设计一个函数接口](./2.1-如何设计一个函数接口)**
  - 按值、`const T&`、`T&`、指针分别表达什么
  - 返回值优先
  - optional 参数与返回值
  - `std::optional`
  - C++23 的 `std::expected`
  - API 如何表达所有权、可空性和错误
- **[2.2 类与不变式](./2.2-类与不变式)**
  - 封装的真正目的：维护不变式
  - 构造函数与成员初始化
  - public/private
  - `const` 成员函数
  - 一个类型什么时候值得成为类
  - 普通聚合 `struct` 什么时候更合适
- **[2.3 值语义、复制与移动](./2.3-值语义、复制与移动)**
  - 对象复制到底意味着什么
  - 析构、复制、移动之间的关系
  - Rule of Zero 应当先讲
  - Rule of Five 作为理解底层机制的内容
  - 移动不是“更快的复制”
  - moved-from 对象和异常安全
- **[2.4 标准库与资源管理](./2.4-标准库与资源管理)**
  - 资源不只是内存：文件、锁、socket、数据库连接
  - 构造获取、析构释放
  - 为什么尽量不直接写 `new` / `delete`
  - `std::unique_ptr`
  - `std::shared_ptr` 为什么不是默认选择
  - 裸指针通常如何表达「观察但不拥有」
- **[2.5 虚函数与运行时多态](./2.5-虚函数与运行时多态)**

- **[2.6 模板与泛型编程](./2.6-模板与泛型编程)**

  - `std::variant` 与封闭类型集合

- **[2.7 迭代器、范围与算法](./2.7-迭代器、范围与算法)**
  - 容器、范围与迭代器
  - `begin` / `end`、迭代器失效与边界
  - 标准算法与迭代器参数
  - 范围 `for` 与 ranges 视图
  - 算法、范围管道与手写循环的选择
- **[2.8 重写成绩程序](./2.8-重写成绩程序)**
  - 从原始程序到分层的小程序
  - `Score`、`Student` 与输入输出职责
  - 用标准库、算法和范围表达业务逻辑
  - 从示例程序过渡到小型项目
