# LinhoNotes

[![Deploy VitePress site to Pages](https://github.com/Linho1219/LinhoNotes/actions/workflows/deploy.yml/badge.svg)](https://github.com/Linho1219/LinhoNotes/actions/workflows/deploy.yml)

网站地址：<https://notes.linho.cc/>

一个 Markdown 笔记仓库。各个方向的内容都有：有学校课程笔记、自学笔记，有数学、物理、计算机、测绘、驾考等等内容，未来可能还会有更多。

网站使用 VitePress 搭建并部署在 GitHub Pages。网站上加入了一些适合笔记的插件，例如交互式函数图像、GeoGebra、地图等。

我们希望更多的人能参与进来！如果你发现某篇文档有错误或需要补充，可以提 issue 或者 PR。若想长期参与贡献或将你已有的笔记迁移过来，可以联系 <lhp@linho.cc>。另请参阅 [仓库贡献指南](https://notes.linho.cc/eiccdqz4)。

若你想要自行部署，可以参考 [.github/workflows/deploy.yml](https://github.com/Linho1219/LinhoNotes/blob/main/.github/workflows/deploy.yml) 或者 [VitePress 文档](https://vitepress.dev/zh/)。

除特别说明之外，本仓库的文档部分采用 [知识共享署名 4.0 许可协议](https://creativecommons.org/licenses/by/4.0/) 进行许可，代码部分采用 [MIT 协议](https://github.com/Linho1219/LinhoNotes/blob/main/.vitepress/LICENSE) 进行许可。
