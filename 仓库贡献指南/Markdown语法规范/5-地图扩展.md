# 地图扩展 <Tag blue>beta</Tag>

使用 [GeoJSON](https://geojson.org/) 编辑标记点后，可以导入并在网站上展示。沿用 VitePress 提供的文件导入语法，使用 `<<<` 导入 `*.geojson` 文件。支持点、线、面。

使用 `properties` 中的 `color` 字段自定义颜色。对于点，可以使用 `label` 字段定义显示标签。

可以使用 mapbox 提供的 [geojson.io](https://geojson.io/) 在线编辑 GeoJSON 文件。

```markdown
<<< ./images/pudong-riverside-bikelane.geojson

<<< ./images/lujiazui-observation-decks.geojson
```

渲染为：

<<< ./images/pudong-riverside-bikelane.geojson

<<< ./images/lujiazui-observation-decks.geojson

感谢 [OpenFreeMap](https://openfreemap.org/) 提供公益性质的矢量地图瓦片服务，感谢 [OpenStreetMap](https://www.openstreetmap.org/) 贡献者们提供的地图数据。

地图样式修改自 [OpenFreemap Bright](https://tiles.openfreemap.org/styles/bright)，深色模式配色参考了高德地图。
